第一轮判据不要追求“完整转写正确”。只看以下问题：

1. `nakigoe / mezameta / sora` 的关键辅音、元音骨架是否还能从 greedy decode 中看出来；
2. 实际候选是否持续比 `nakikoe / mesameta / uchuu` 得到更高声学对齐分数；
3. 分差是否在不同片段上稳定，而不是偶然高一点；
4. 如果自由解码很脏但候选比较稳定正确，就继续做“已知歌词约束下的候选比较”。

`score` 和 `margin` 目前都只是实验量，不设置正式阈值，也不能直接解释成概率。
